## Step 0 review of merged 13e (before changes)

Reviewed `docs/phase-13e-preregistration.md`, `docs/phase-13e-moving-slot.md`, `src/slot.rs`, and the planner execution in `src/network.rs` at `5f7cf77`. The checkout was clean; no partial 13e code or commits were carried over.

- **Unsupported impossibility claim.** The same-connector observation explains why a parallel clone is not an independent bypass. It does not establish that no useful move exists: removing an ordinary predecessor can change queue order before the shared connector. Broadcast's positive gain already requires an explanation of that possibility. 13e's zero is evidence about its implemented planner, not all plans or prices.
- **Forecast is not host physics.** `forecast` uses a simplified per-link acceleration/following update (1.8 m/s², simple 1.2 s headway), rather than the host IDM integration. It omits junction claim arbitration, exit-room constraints, cross-link bodies, not-yet-spawned demand and receiver decisions. The “same car-following model” wording overstates this. Free-flow slot timing plus a 120 s horizon is especially weak in a queue lasting hundreds of seconds.
- **Conflict exclusion builds in inaction.** `open_lane` and `spill_diversions` move the optimistic slot beside the queue. Original-lane queued cars then cease to be body-overlap conflicts. `hole_closes` / `lane_is_busy` rule out extraction when following traffic would refill the hole; they do not solve the coupled extraction-and-return problem. Tests of these exclusions cannot prove the optimality of doing nothing.
- **“Cheapest” is an action ordering, not a cost proof.** It does not jointly optimize multiple cars, compare realized waiting, or prove minimal message timing. Dispatch can expand a predicted hold to the remaining existing 3 s budget. A six-second return attempt is not a six-second return guarantee; safe-gap failure can last much longer.
- **Evidence and generalization are limited.** One deliberately fixed hypothetical incident on OSM geometry, historical 2013 midpoint demand, no measured cross-street flows, lane caps and uncalibrated junction behavior do not establish a real operational benefit or safety. The headline's “real” needs this qualification. Both 0 s and passing a delay bar can be achieved by ineffective inaction.
- **Score interpretation needs care.** 13e silently filters missing arrival pairs; completion is reported separately. It labels broadcast `lane_change` as `gap_shift` in move summaries although broadcast's braking/rejoin behavior differs. Its cost tables use signed arrival differences and positive-loss sums, not literal commanded hold seconds. 13f makes pair coverage explicit and retains per-car evidence.

The frozen hashes and published zero result are reproducible. These criticisms do not justify replacing them. No earlier partial implementation exists here to compare or port.
