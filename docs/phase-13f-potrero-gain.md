Base: `5f7cf77ef5b3d979d40bb833b56a0bd037936e0f` (PRs #38 and #39).
Step 0 review was completed before instrumentation; its findings are at the top
of the PR description. The checkout was clean and contained no partial 13e work.
No 13e code was ported. This step replays unchanged arms; it does not tune them.

## Mechanism and the contradiction

**Queue extraction:** ask a queued ordinary driver ahead of the ambulance to
pull into the parallel lane. The ambulance takes an earlier place in the
original lane's queue. This changes its turn at a shared connector, even though
the parallel is not a bypass of that connector. It can save time without passing
the incident while it is active. The displaced car often cannot rejoin until
much later. This is a redistribution of waiting, not new road capacity.

All ten seeds issued **zero holds and zero reroutes**. Lane changes occurred
only on road edges 13, 14 and 15. `clear` messages also occurred, but a diagnostic
replay of broadcast with `lane_changes=false, reroutes=false` produces
**identical arrival times for every driver to local-only on all ten seeds**.
On this single-direction demand, clear precedence by itself cannot change the
same-lane queue order. The diagnostic is not an additional experimental arm.

The queue backs up through Potrero at 19th (node 27, connector 830) and 20th
(node 55, connector 1046, edge 14 → blocked edge 15). The exit from edge 15 at
21st is node 45, connector 964. Lane changes upstream remove predecessors
before 1046; changes on edge 15 remove predecessors before 964. Subsequent
probes inherit earlier extractions, so a probe can gain without a new direct ask.
All emergency entries into 1046 in these runs occur **after the blockage ends
at t=540**. Do not describe the gain as an ambulance driving through the truck
or around an active blocked connector. Some probes gain further downstream;
the complete connector-by-connector entries are in the trace JSONL.

13e's 0 s is reproduced and remains reported. Its planner generally puts its
optimistic slot on the empty parallel beside the queue, declares the original
queue outside that slot, then refuses the queue extraction because a follower
would fill the return hole. Those are sufficient reasons for this implementation
to do nothing. They are not proof that no gainful move exists. Broadcast's
costly queue extraction is the counterexample. Whether a cheaper extraction
passes the unchanged fairness bar is the next experiment, not an inference here.

## Reproduce

```bash
cargo run --offline --release --example phase13f_trace -- /tmp/phase13f-traces
python3 scripts/phase13f-mechanism.py /tmp/phase13f-traces
```

The exporter stores existing one-second frames, messages and exact home times.
It calls only `Mock`; no live policy or API key is used. The summary checks the
clear-only diagnostic against **all** local home times, not just emergencies.
This establishes the mechanism class, not a unique additive causal value for
each removed driver: interacting queue changes are not additive. No individual
lane-change ablation has been run, so such an attribution would be unproven.
